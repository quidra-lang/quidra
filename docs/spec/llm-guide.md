# Quidra LLM Guide

## Canonical generation rules

Core typing rule: ordinary value arguments never specialize a call's static return type from their values. Values may determine runtime behavior and compile-time facts used for diagnostics or optimization, while generic specialization resolution may depend on argument static types. An expected type may explicitly constrain a result. Do not turn a known argument value into a narrower source-visible return type.

1. Use four spaces for each block level. Dedentation closes a block. Use spaces exclusively.
2. Write explicit return and parameter types: `int add(int a, int b = 1)`.
3. Prefer `auto x = expression` when the inferred type is obvious from the initializer on the same line, such as `auto point = Point(1.0, 2.0)` for `class Point(real64 x, real64 y)` or `auto image = tensor.zeros<real32>([3, 224, 224])`. Otherwise prefer the complete type before the name, such as `Point point = make_point()`, when a helper's result requires looking up its declaration. This is a readability recommendation; otherwise valid inference remains accepted without additional warnings or errors. Apply the same guidance to `const auto` and `auto | error`. Bare `auto` infers the complete non-`error` success side and fails fast on `error`; ordinary alternatives such as `none` remain. Use the dedicated `auto | error x = expression` form when the success type should be inferred but the `error` channel must remain available to `match`. `auto` is not allowed in any other union.
4. An initializer can be omitted from a typed declaration. A read that no path initializes is a compile-time error; a read that only some paths initialize compiles and stops with `UNINITIALIZED` at run time on a path that left it uninitialized, so initialize on every continuing path whenever the value is needed.
5. Array indices refer to existing elements. `[]` is an initialized empty array; indexing it at zero fails unless it has first been replaced by a non-empty value. Constant out-of-bounds indices are compile-time errors when the array type has a statically known length; dynamic arrays remain runtime checked. An index may have any integer kind. Lengths, counts, shapes, sizes and API index values (`len`, `size()`, `.shape()`, `find`) are `nat`: `len(a) - 1` fails on an empty array, so compute with `int(len(a)) - 1` where the result may be negative, write `int(len(v))` to use a length as an `int`, and pass `nat(n)` where an API takes a count or shape and `n` has another integer kind. Slice an array with `a[s:e]` (both ends included; ascending when s <= e, descending when s > e), `a[s:<e]` (the end excluded) or `a[s<:e]` (the start excluded). `a[4:0]` selects 4 through 0. Direction markers touch the colon: `<` ascends and `>` descends. An explicit step determines direction and must agree with markers; use `a[start:end:1]` or `a[start:end:-1]` when dynamic endpoints must not change direction. Two explicit endpoints reversed against that step are an error, even with an exclusive side. Omitted endpoints use the sequence's ends; `a[:]` and `a[2:]` ascend by default, and `a[::-1]` reverses. A slice is a new, independent array; `a[1:3] = b` stores an array of exactly as many elements into the selected ones.
6. Create a runtime-sized filled array with `array(n, fill = 0)`. Fixed sizes are type contracts; respect all dimensions. Grow an array with `values = values.append(value)` or combine arrays with `values.concat(other)`; these return new values rather than resizing referenced storage in place. For numeric, bool, or string arrays of either fixed or runtime size, use `values.sorted()` for a non-mutating runtime-sized sorted copy, and `values.sorted(descending = true)` for descending order (always named), instead of hand-writing a sort unless the algorithm itself is the task.
7. Use `return` for explicit control flow. Use `elif` for a same-level conditional chain instead of nesting `else` + `if`. For a value, use the if-expression `if C then A else B`, chained with `elif`, never `else if`; there is no `?:`. Compound assignment (`+=`, `-=`, `*=`, `/=`, `%=`) evaluates its target exactly once; prefer it when the read-modify-write operation is the intended meaning. A `void` function can use bare `return` or reach the end of its body.
8. Use `T | error` for failure, `T | none` for normal absence, and `T | none | error` when both are possible. Return the actual value directly.
9. `try expression` propagates only `error` from a compatible function and removes it from the expression's type. Make errors with `error("text")`, give them a code with `code = "DATASET_LOAD"` (capital letters, digits and single underscores; package code requires an explicit code starting with its prefix, `NN_...`), and wrap a lower error to add context with `cause = problem`. Branch on `e.code` and on details such as `e.reason` (read through `match`: they are `string | none`); `e.message` is the text, `e.cause` the wrapped error as `error | none`.
10. Cover every alternative in `match` using `T`, `T name`, or `none`. When matching a variable, its name has the selected type inside that case. A class value must be fully definitely initialized before it enters a union, so a matched class alternative is fully initialized.
11. Named arguments use `name = value`, follow positional arguments, and occur at most once per parameter. For capture-free function values, write an explicit type such as `func<int>(int) operation = twice`. Do not infer one with `auto`. The declaration must match the `func` result/parameter types exactly, may not use reference parameters, and an `extern` function or bound method is not a function value. Call a named function-value binding with positional value arguments.
12. `&storage` means the safe address of existing storage. It is not a numeric pointer. Do not invent `*`, pointer arithmetic, address-to-int conversion, or `is`.
13. Storage access is explicit at function boundaries: declare `int[] &values` for read/write access and call it with `process(&data)` or a named `&values = &data`. For read-only input declare `const int[] values` and pass `data`; `const T &` is never valid.
14. Create aliases with `T &alias = &storage`; an unbound local `T &alias` must be bound before access. A class reference field may be initialized explicitly with `&`, or bound/rebound only inside its declaring class with `&name = &storage`. Reference fields have no const qualifier. `&` is storage authority, never part of an array/tuple/generic/union/function result type.
15. `const T value = expression` creates an immutable value; `const auto` may infer T. Initialization is required. A const parameter takes a value, `f(data)`, never `&data`; the compiler borrows without a copy when safe and copies where another access may change it. No writable reference may be formed from a const value, including through a const holder's reference fields. `const T &` is `CONST_REFERENCE`. Taking an address does not read its target; never address a temporary.
16. A stored reference field may target only a whole variable or a path of class fields beneath stable variable storage; storing an array element, tuple element, union payload, map/set entry, unresolved place or temporary is REFERENCE_TARGET. Its target must be bound and initialized, and later replacements must preserve initialization. Local references may still capture array elements. References keep targets alive, including after escape or replacement of a containing value; a captured field then stays on detached storage. A whole-variable reference observes later replacement. Never store a holder inside the value it refers into: keep a model and its bound optimizer in separate variables. Separate-variable cycles are allowed and may retain storage.
17. Ordinary arguments have value semantics, `const` ones included. Reference arguments share the addressed storage and carry read/write authority: `&` is storage access, and `const` makes a value immutable.
18. Iterate values with `for auto value = values[]`, references with `for auto &value = &values[]`, and ranges with `for start <= nat i < stop step 2`. Use `for nat i < stop` for an implicit inclusive zero start. A real range requires an explicit step. Use `_` to repeat by count without binding a value. Use `continue` to advance the nearest loop and `break` to leave it; both are invalid outside loops.
19. Put required parameters before defaulted parameters. Type every default parameter. Defaults are fresh per omitted call and cannot reference parameters/caller locals. Reference parameters have no defaults.
20. Conditions are booleans. Combine them with `and`, `or`, and `not`; do not invent `&&`, `||`, `!`, or truthiness coercions. Comparisons chain in one direction: `0 <= i < n` and `a == b == c` are valid, `a < b > c` and every `!=` chain are errors, and the result of a comparison is compared only in parentheses, `(a < b) == c`. Numeric operands have matching types. Built-in numeric types are `int8`, `int16`, `int32`, `int64`, `int`, `nat8`, `nat16`, `nat32`, `nat64`, `nat`, `real16`, `real16b`, `real32`, `real64`, `real`, and the complex `com16`, `com16b`, `com32`, `com64`, `com`; there is no `char`. Complex values have no ordering and never mix with reals: write `com32(x)`, `z.real`, `z.imag`, and literals `1.0 + 2.0i`. `int` and `nat` are exact and never overflow; a `nat` result below zero fails. For fixed-width integer bit operations use uppercase `AND`, `OR`, `XOR`, unary `NOT`, `<<`, and `>>`; never apply them to bool, fixed-width reals, `int`, `nat`, `real`, bin, tensor, or tensor values (use `int64` for bit patterns).
21. Never change an already-typed numeric value's representation implicitly. Numeric literals may take a contextual numeric type of their category when representable: an integer literal materializes only as `nat*` or `int*` (a negative one, such as `-10` or `-0`, only as `int*`), a real literal only as `real*` (write `10.0` or `real32(10)`, never `real32 x = 10`), and a compound literal expression computes in the context type, so `nat8 x = 3 - 5` is a compile-time error. Explicit `T(value)` conversion is practical: a runtime range-checked conversion has type `converted-type | error` (for arrays and tensors the success side is the whole converted container, atomically; bare `auto` infers that success type and fails fast, while `auto | error` preserves failure), integer-to-real and real-to-real may deterministically round, and real-to-integer accepts only mathematically integral values in range (otherwise `T | error` reports `NOT_INTEGRAL`, `OUT_OF_RANGE`, or an exact proof’s `UNDECIDED`). Import the first-party `math` package before using `math.trunc`, `math.round`, `math.floor`, `math.ceil`, or other mathematical APIs. Never use a cast to request wrap or clamp. Mathematical functions are package-namespaced only: after `import math`, write `math.abs`, `math.sqrt`, `math.min`, and `math.max`; the bare spellings do not exist.
22. Parse text with a numeric type method such as `int.parse(text)` and convert scalar values to text with `value.string()`. Parsing and casting are different operations. Float text is shortest-round-trip decimal while retaining `.0` when an otherwise integral-looking representation needs to remain visibly floating-point. Signed infinities are valid real values, but NaN is forbidden. Real overflow, nonzero division by zero and zero to a negative real power may produce infinity; indeterminate operations fail. Use `inf` and `-inf` explicitly. Exact `real` prints `∞`/`-∞`, fixed-width types `inf`/`-inf`. Finite out-of-range literals and narrowing casts remain errors.
23. Use `print(value)` for standard output; it never adds a newline. Add `NL` explicitly when a line break is intended, for example `print("answer: {value}{NL}")`. `print` and `flush()` return `void | error` and fail fast when written as statements. Core has no `write` builtin. Read input with `scan`: `scan(&n)` reads one value into `n`, and `scan("{&n} {&m}")` or `scan("{&name},{&age}")` reads a line against a format whose literal text must match the input, parsing each `{&target}` by the target's numeric or `string` type. A `string` target takes the whole rest of the line. `scan` returns `void | error`; as a statement it fails fast and initializes its targets, and `void | error read = scan(...)` keeps the error, in which case the targets must already be initialized. There is no `input()`. Use string interpolation such as `"answer: {value}"`. Numeric interpolation may use only `int=N`, `frac=N`, `sig=N`, and `zero`, for example `"{value:int=4,frac=2,zero}"`. Do not combine `frac` with `sig`, and do not use `zero` without `int`. For an exact `real`, `int` and `zero` need `frac` or `sig`.
24. Quidra has no backslash escapes. Write backslashes literally and use `NL`, `HT`, `CR`, `DQ`, `BS`, `FF`, `VT`, and `BL` for LF, HT, CR, quote, BS, FF, VT, and BEL. These eight are two-letter uppercase built-in values. Lowercase spellings such as `nl`, `ht`, and `bs` are ordinary identifiers, not aliases for them.
25. Reserved identifiers cannot be reused by user declarations. `this` and `construct` are ordinary identifiers. Never shadow a visible declaration; reuse is allowed in disjoint scopes. Class members, the optional instance name, header locals and method/block declarations must not conflict. Imported module namespaces do not make reserved bare names reusable.
26. Define a class with `class Point(real64 x, real64 y)` or `class Point self(real64 x, real64 y)`. The argument list is mandatory. Ordinary header parameters are members; `local` parameters are initialization-only. `Point(...)` initializes header members, then runs direct statements/member initializers in written order. Methods run only when called. Use header defaults or free factories for alternate forms; `construct` has no special status. `class Point(...) | error` permits generation errors; successful union results require full initialization. Private members are accessible only in their declaring class.
27. A typed bare declaration `Point p` declares an uninitialized binding and creates no usable instance. Before member reads, member writes, method calls or instance borrowing, initialize or assign the whole binding with `Point(...)`; `Point p(args)` is equivalent to `Point p = Point(args)`. Copying an initialized instance does not rerun generation. Bare standard Map/Set retain empty-storage initialization. Fields without an initializer remain uninitialized. Keep mandatory resource success operations explicit; failed generation cleans owned members and locals without rolling back external effects.
28. Expressions evaluate left to right; assignment evaluates target indices, then the right-hand side, then stores (`a[i] = bump(&i)` writes at the old i). Ordinary value fields are independent after a copy; class copies preserve initialization and binding state. Reference fields explicitly share their original targets across holder and container copies. A later write through either copied reference reaches that shared target. Only explicit `&` permits observable sharing.
29. Use bare member names inside a class (`count += 1`, `return x * x`, `bump(&total)`). An optional header instance name denotes the fixed whole instance, permits ordinary value use and explicit `&self`, and cannot be replaced/rebound or escape during initialization. No implicit `this` exists; `class C this(...)` explicitly declares that name. Method receiver read/write requirements remain inferred.
30. Classes contain only their declared fields and methods. Reuse behavior and state through explicit composition; use an explicit union and exhaustive `match` when several concrete class types are possible.
31. Class, array, tuple and bin equality compares values. Reference fields compare target values, never addresses; `&left == &right` compares addresses explicitly. Every compared value must be initialized and every visited reference field bound; untracked holder fields are checked at run time. REPL display also checks bindings.
32. Put imports at top level. Standard namespaces are already visible and must not be imported. Use `import module = "./file.qui"` for importer-relative files, `import module = "@/file.qui"` for command-root files, and `import plot = plotting` for an installed package. Access imported declarations through the alias. Mark a top-level function, `extern`, class, enum or `const` binding `private` when it is an implementation detail of its module: importers cannot name it, and no public declaration may expose a private class or enum in its signature, public fields, payloads or constant types.
33. Imported module files may contain declarations, immutable top-level `const` bindings with side-effect-free scalar constant initializers, and top-level `if main` self-test/example guards. Access exported constants through the module namespace; importing them performs no module initialization. An imported file's own `main` is false, so guarded bodies do not execute, although they are still parsed and type-checked. Do not put any other executable top-level statement in an imported file, do not create import cycles, and do not rely on a nested import being re-exported.
34. Declare generics with `class Box<T>(T value)`, `T first<T>(T[] values)` or `T method<T>(T value)`. Generic class/function/method arguments may be inferred only when all parameters follow uniquely from typed call arguments; untyped numeric literals determine no generic argument, so write `Box<int>(7)`. Use ordinary generic factories for extra initialization type parameters. Ordinary overloading is forbidden; specialization families retain one call shape and resolve by exact/narrower static matches.
35. Generic bodies are monomorphized and checked after substitution. Do not assume an operation is valid for every `T`; it must be valid for each concrete instantiation actually used.
36. Top-level statements in the directly executed root are the entrypoint. Use exact top-level `if main` for code that should run only when that file itself is the root; it has no `elif`/`else`, and `main` is not an ordinary user binding. Choose descriptive function names for reusable computations.
37. Format one-line lists without a trailing comma and multiline lists with one.
38. Use `bin.fill(n, bit)` for allocated raw bits and `bin.parse("0101")` for written bit patterns. `bin.parse` has static type `bin | error` even for a valid literal; handle the union with `match` or `try`. A known-invalid literal may be rejected early and a known-valid literal may be optimized internally without changing that type. `bin(value)` is reserved for explicit conversion. `len(bin)` counts bits; indexing returns a one-bit `bin`, slicing (the forms of array slices, no step) returns `bin`, and value/writable iteration operates one bit at a time.
39. Treat `string` as immutable UTF-8 text and `bin` as packed raw bits. Repeat one Unicode code point with `string.repeat(value, n)` rather than overloading `string(...)`. `len(string)`, `text[index]`, `find`, and slices `text[a:<b]` use Unicode code-point positions; string indexing returns a one-code-point `string`, and a slice is a `string`. `text.utf8()` returns `bin`, while `text.codepoints()` returns Unicode scalar values as `int[]`. Do not invent `char`, `bit`, `byte`, or `bytes` source types.
40. Use `while condition` for condition-controlled repetition. The condition must be `bool`; `break` and `continue` target the nearest loop. Prefer `for` when iterating an existing range or collection and `while` when progress is state- or convergence-driven.
41. For a command-line program, declare exactly one top-level `cli name` block; the `cli` namespace is already available and is not imported. Inside the block, use `argument()` for required positional fields, `argument(default = value)` for trailing optional positional fields, `option(default = value)` for named options, and `flag()` for boolean flags. CLI scalar fields accept `string`, `bool`, and every integer or real kind; numeric parsing checks the declared representation and accepts only finite reals. Read parsed values as fields of that binding. The binding is not implicitly visible inside functions because functions do not capture top-level bindings; pass the needed CLI-derived values explicitly.
42. Method selection is static and local to the receiver's concrete class declaration. Do not invent dynamic dispatch or hidden subtype relationships.
43. Standard namespaces are always visible and cannot be imported or aliased: `cli`, `file`, `environment`, `test`, `time`, `gpu`, `autograd`, `reflect`, `random`, `process`, `map`, `set`, `json`, `http`, `tensor`. `math` is an installed package, so use `import math` before `math.*`. Unquoted non-standard imports are installed packages and never fall back to local files. Use `file.is_directory(path)` to distinguish directories from files. Use `file.list(path)` for deterministic direct-child enumeration or `file.list(path, recursive = true)` for deterministic recursive enumeration; both list forms return sorted paths as `string[] | error`. Use `file.open/create/append` when incremental Handle-based I/O is required; `read_line()` returns `string | none | error`. Use `json.integer()` for an exact `int` and `json.real()` for an exact `real`; `json.number()` returns `real64`. `Generator.int(start, end)` takes arbitrary-precision `int` bounds. `time.seconds(value)` accepts finite integers and reals, with explicit internal conversion to `real64`; it rejects complex values.

44. Use `array(n)` only with an explicit array type context when intentionally creating uninitialized elements. Use `array(n, fill = value)` for a fully initialized array; `auto x = array(n)` is invalid because the element type is unknown.
45. Use `tensor<T>(shape)` for intentionally uninitialized dense numeric tensor storage, and `tensor.zeros<T>(shape)` or `tensor.ones<T>(shape)` for initialized storage. An expected tensor type may supply the element type even when the shape is explicit, so prefer `tensor<real32> x = tensor.zeros([2, 3])` over repeating `real32` on both sides. `auto x = tensor.zeros([2, 3])` is invalid because no element type is available. With a fully known expected exact shape in braces, contextual `tensor.zeros()` / `tensor.ones()` may derive both dtype and extents; any `_` axis or unconstrained rank still requires an explicit shape argument. Tensor indexing always returns `tensor<T>`; call `.item()` only on a 0-D tensor to obtain a scalar.
46. Tensor-to-tensor implicit broadcasting requires equal rank and per-axis equality or singleton expansion. Do not rely on NumPy-style rank prepending. Use explicit `.reshape(...)` when rank must change.
47. Tensor slices may be internal views, but value semantics are preserved with copy-on-write. They ascend: `t[a:b]` includes `b`, `t[a:<b]` excludes it, `t[a<:b]` excludes `a`, and a step is positive. `.reshape(...)` requires contiguous storage and never hides a materializing copy; use `.contiguous()` explicitly. Write shape contracts in braces after `tensor<T>`; omit `...` to require exact rank: in a shape, `nat N` declares a shape variable (the axis's extent) and `nat N = EXPR` declares one equal to EXPR; a bare name must be an existing shape variable or nat value and means equal; any other expression is a constraint; `_` is an axis of any length that binds nothing; write `{nat(n)}` for an `int n`. A shape is one scope, so `{nat N, N}` is square and `{nat M = 2 * N, nat N}` is valid; shape variables are read-only `nat` values. A signature is one scope: its result shape may use variables declared in any parameter shape, and derived extents follow dependency order. Constructors, external declarations and `func` types use the same rules. Array dimensions are `nat` expressions; write `real64[][nat(n * m)]` for integer variables. Evaluate a captured extent once, and keep its value for later checks. Use the scalar destination type as the only numeric cast syntax: `real64(array)` recursively preserves array structure and `real64(tensor)` preserves tensor rank/shape facts. When a leaf conversion is range-checked, the result is the whole converted array/tensor `| error`; no element-level union is introduced. Explicit casts between floating tensor types preserve tracking: `real16(x)` rounds a real32 master weight in forward and casts its gradient back to real32 in backward. Use the ordinary narrowing conversion’s `| error` rule. Tracked integer, bool and complex casts are rejected; `.untrack()` explicitly cuts provenance before such a cast. Higher-order graphs containing real16 or real16b remain unsupported, including a widened loss. Do not invent a container-specific cast method.
48. Core owns tensor/storage/autograd/device mechanisms and the basic language/tensor operators `+`, `-`, `*`, `/`, `%`, `^`, and comparisons. Mathematical unary functions and numerical reductions are package semantics: `import math`, then use `math.abs(value)`, `math.sqrt(value)`, `math.log(value)`, `math.exp(value)`, `math.sum(value)`, `math.mean(value)`, `math.sum_last(value)`, `math.max_last(value)`, and `math.min_last(value)`. Array `sum`, `mean`, `min_all` and `max_all` are also Math APIs: `sum` returns the element type and typed zero for an empty array; integer `mean` returns exact `real`, while other numeric means keep the element type. Extrema require ordered elements. Empty means and extrema report `MATH_SHAPE`. Do not add a Core primitive merely because it is common, accelerated, differentiable, or compiler-optimizable.
49. Import the first-party `math` package for generic mathematics and linear algebra such as `math.dot(a, b)` and `math.matmul(a, b)`; Core intentionally does not own matrix-multiplication semantics. Matrix multiplication has no `@` operator.
50. Image and video APIs are package-owned. Use `import vision` and call `vision.read<T>(path, channels = ...)` / `vision.write(path, pixels, quality = ...)` for image I/O and transforms; use `import video` and `video.open(path)` / `video.Reader` for video decoding. Do not invent `image` or `video` Core namespaces, hidden CPU/GPU transfers, or compiler-special handling for these packages.
51. An `autograd.Target` copy has a fresh identity and an independent copy of its pending gradient; sharing a destination uses `&`. Leaves tracked before copying still name the original. Floating `tensor<T>` values are untracked by default; use `.track()`, `.untrack()`, and `.retrack()` to control autograd explicitly. Shape braces constrain tensor rank and extents independently of tracking. Without `...`, rank is exact; one `...` means zero or more axes, with prefix constraints aligned from the head and suffix constraints from the tail. `_` means exactly one axis. `{..., nat C}` binds the last axis; prefer `tensor<T>` to the equivalent `tensor<T>{...}`. Autograd lives on ordinary floating tensors; architecture-independent neural-network state, optimizers, persistence, and distributed-training policy belong to the `nn` package. The `dnn` package only composes concrete deep-neural-network model architectures.


52. Do not invent domain APIs in Core. Import the package that owns the domain semantics instead.
53. Declare C FFI only with top-level `extern` declarations. Results may be only `void` or ABI-stable scalar values. Parameters may additionally use `string` or `bin` as call-scoped read-only borrows; each lowers to an adjacent C `(data pointer, nat64 byte length)` pair. Do not assume a pointer-only C string, implicit NUL-terminated foreign contract, encoding conversion, ownership transfer, pointer retention, or mutation. Use an explicit C wrapper when the foreign API has a different signature, and represent foreign failure explicitly with a scalar status/result rather than inferring `errno` or null semantics.

## Complete example

```quidra
int | error value(bool valid)
    if valid
        return 21
    return error("invalid value")

int | error doubled(bool valid)
    auto x = try value(valid)
    return x * 2

void scale(int[] &values, int factor = 2)
    for auto &item = &values[]
        item = item * factor

int[] values = [1, 2, 3]
scale(&values = &values)

int pending
int &alias = &pending
alias = 7

match doubled(true)
    int answer
        print(answer)
        print(NL)
    error problem
        print(problem)
        print(NL)
```

## Verification

Run `quidra check source.qui --json` for diagnostics, then `quidra run source.qui` to check native behavior. `quidra inspect` exposes source structure; prefer `--no-source`, `--no-effects`, `--kind KIND`, and `--depth N` when a task needs only a compact subset. Nodes include `parent_id` and `depth`, so callers do not need to reconstruct hierarchy from spans. `quidra patch` applies revision/hash-checked changes using the schema in `patch-schema.md`. Check both intended results and error paths. Preserve the explicit write contracts and fixed shapes when modifying code.

The current core includes fixed-width numeric types, explicit conversion, initialized/uninitialized arrays, dense tensors with slicing/COW/broadcasting, the basic tensor operators `+`, `-`, `*`, `/`, `%`, `^` and comparisons, generic tensor/autograd/device and package-extension mechanisms, file and console I/O, monomorphized generics, classes, references, unions, and explicit composition. Mathematical unary functions and numerical reductions, linear algebra, DNN, vision, video, and other higher-level semantics belong to packages.

## Output and tensor initialization

- `print` accepts scalar/text values, not whole arrays or tensors, and does not append a newline. Print elements and `NL` explicitly or format them intentionally.
- `tensor<T>(shape)` creates uninitialized elements; initialize scalar elements with indexed assignment, or use `tensor.zeros<T>(shape)` / `tensor.ones<T>(shape)` when a fully initialized tensor is intended.


### Writable arguments and explicit conversion

For writable named arguments write `&name = &value`; positional writable arguments remain `&value`.

Already-typed numeric values never change representation implicitly, even when the conversion would be lossless. Numeric literals may materialize directly in a unique compatible numeric context. Explicit integer-to-real and real-to-real conversion may round; range-checked conversion has type `converted-type | error`, with arrays and tensors represented as one atomic converted-container success alternative, so bare `auto` infers the success type and fails fast while `auto | error` preserves failure. Do not generically cast real64 to integer: choose `math.trunc`, `math.round`, `math.floor`, or `math.ceil`.

54. Tracked tensor scalar arithmetic uses the tensor element dtype. Numeric literals may be used directly only when exactly representable in that dtype; otherwise cast explicitly.

55. Core autograd lives on ordinary floating `tensor<T>` values. Core exposes no Parameter, State, model, layer, optimizer, or model-persistence abstraction; use `import nn` for architecture-independent neural-network concepts and `import dnn` only for concrete deep-neural-network model compositions.

56. Keep models as ordinary classes. Use `nn.Parameter<T>` for learnable storage and `nn.State<T>` for persistent non-learning tensor state such as BatchNorm running statistics. Leave transient caches as ordinary tensor/scalar fields rather than turning them into State. Both abstractions live in the NN package; `nn.Parameter<T>` owns a private Core `autograd.Target` for gradient state, while `nn.State<T>` has no gradient destination. Neither requires hidden compiler registration or a Module base class.



57. Use `tensor.track()` to start a graph, `tensor.untrack()` to disconnect it, and `tensor.retrack()` to cut the previous graph and start a new tracked root. Reverse mode always names writable destinations: `loss.backward(&x)`, `loss.backward(&encoder, &decoder)`, or `loss.backward(&model, &input)`. Targetless `backward()` is invalid. Repeated calls accumulate until the destination is explicitly cleared. Ordinary tensor copies never share gradient state; Core matches graph leaves by logical autograd identity rather than tensor storage identity. Use a final `track = true` for higher-order gradients, for example `loss.backward(&x, track = true)`. Tracked `reshape` and `transpose` preserve the graph; `contiguous`, indexing/slicing, `gpu`, and `cpu` currently require explicit `untrack()` first rather than detaching silently.

58. Numerical reductions are Math-package-owned. After `import math`, `math.sum(value)` and `math.mean(value)` return rank-0 tensors; `math.sum_last(value)`, `math.max_last(value)`, and `math.min_last(value)` retain shape by broadcasting the reduced value across the last axis. Core must not grow dedicated numerical reduction callables, autograd op identities, runtime kernels, or backend policy.

59. Architecture-independent normalization, activations, dropout, reusable layers, losses, optimizers, schedulers, and NN-specific rewrites belong to the `nn` package. Dropout uses the explicit `random.Generator` API rather than hidden global randomness. Concrete model families belong to the upper `dnn` package.


60. Treat `nn.Parameter<T>` as a package abstraction. Its storage representation is private. Bind an optimizer to the model at construction, `nn.Adam<Net>(&model)`, and call `.optimizer.update()`; it validates structure and gradients before updating and clears the gradients it consumes. A precheck error leaves model and optimizer state unchanged. A computation-time failure can leave their state unspecified: reload a checkpoint and create a new optimizer. Use `nn.clear_grad(&model)` to clear gradients explicitly. Parameter and model copies have independent gradient destinations. Ordinary real32 training keeps parameters, gradients, and Adam moments in real32. To opt into low-precision forward computation while retaining real32 parameters and Adam state, explicitly cast tracked real32 parameters to real16 or real16b. A direct half-precision Parameter instead stores weights and gradients in its own format; optimizer arithmetic widens them to real32, stores each updated weight once in the weight type, and keeps Adam moments in real32.

61. Core does not special-case NN Parameter values: their identity, traversal and gradient access are built from ordinary classes, reference fields, the structural traversal (`reflect.each`) and tensor APIs.

62. Core tracked autograd supports floating `tensor<real16>`, `tensor<real16b>`, `tensor<real32>` and `tensor<real64>`; a real16 or real16b gradient has the tensor's own type, each backward operation computed in real32 and rounded once. The NN package separately constrains `nn.Parameter<T>` to floating element types.

63. For `extern` C declarations, pass numeric/bool scalars by value. Expose text or binary input only as `const string name` / `const bin name` and pass a value at the call (`c_text(text)`), or as `bin &name` with `&storage` for mutable bytes; each such borrow lowers to a read-only no-capture data pointer plus an explicit `nat64` byte length for that call. Do not invent pointer-only C strings, implicit encoding conversion, foreign retention/mutation, hidden ownership transfer, or inferred `errno`/null failure. A `real32`/`real64` value from C (an `extern` result, an `export "C"` argument) that is NaN stops the program where it enters; signed infinities cross unchanged. Expose a Quidra function to C only with `export "C"` on a top-level non-generic function whose parameters use `int8`..`int64`, `nat8`..`nat64`, `real32` or `real64` by value and whose result is one of them or `void`; never `int`, `bool` or a managed type, a default, or a reference parameter.
67. If class initialization changes hidden existing state, call `.Type(...)`; the header has no mutation definition marker. The compiler infers this requirement from the ordered body. Ordinary parameter defaults cannot change existing state. A bare class declaration creates no usable instance and runs no initialization body; whole-binding initialization or assignment is required before instance operations.

68. Runtime failures print `Quidra runtime error[CODE] at FILE:L:C`, the compile-time `FILE:L:C` form, so the position can be opened directly; when the compiled source file is unchanged, a blank line, the source line after its line number (`10 | ...`) and a caret line follow, then the message inside the same gutter (`   | message`). Without the source line the message follows the header as `| message`. The position is the user's statement, never a line inside a package. An error that propagated adds trace lines after an empty body line: `propagated through F() at FILE:L:C`, inner to outer, and `caused by: [CODE] message (at FILE:L:C)` for each wrapped cause, its own hops indented under it. Machine-readable runtime reports come from `QUIDRA_ERROR_FORMAT=json` (one JSON line on stderr with `code`, `message`, `details` and `location`), compile-time positions from `check --json`.

69. An imported typed constant has its declared type everywhere: with `const real32 eps = 1.0e-5` in `mod`, write `real64(mod.eps)` where a `real64` is needed. Declare a constant `const literal real` (for example `const literal real tau = 6.283185307179586`) when every use should take its own real type, as a literal does.

Runtime traps and fail-fast stops also list the user call path, inner to outer, including
inlined calls; `… call path incomplete …` identifies a part the runtime cannot prove.

70. Make every change of existing state visible at the call. A target changed through `&x` needs nothing more. Any other change (receiver fields, shared state reachable from the receiver or a by-value argument, runtime state behind a `.` extern) needs the marker `.` on the definition, `void .increment()`, and one `.` before the whole call chain, `.counter.increment()`, `.counts.set(k, v)`, `.rng.int(1, 6)`, `.handle.write_line(text)`, `.T(...)`. Locals of the function, the value a constructor creates and external I/O (`print`, files by path, `process`, `http`, `environment`, `time`) need no marker. A caller of a `.` function is `.` itself unless it exposes the state with `&` or owns it as a fresh local. Never mark a call that reaches no `.` callee, never turn a `.` function into an `func` value, and ordinary parameter defaults must not change existing state; class member initialization follows the inferred generation call marker.

71. A shaped function checks each unproven argument relation once at entry. A result may derive an extent with `nat L = EXPR`, but cannot declare an uninferred bare `nat L`. A matching `func` type may rename shape variables while preserving their equality relationships. Function values always call the checking wrapper; a proven direct call may enter the checked body directly. External tensor calls check unproven argument shapes before the call and every shaped mutable borrow after it.

Use `parallel` for independent nodes and compiler-derived data dependencies. Each direct statement is one node; bindings stay inside its suite. Unordered writes and I/O conflicts are rejected. A loop is a single sequential node. Every started node joins; failures are selected in source order, and independent nodes still finish. Control cannot leave a node. Nested blocks and package kernels share the bounded worker pool. `task` and `atomic` are ordinary names.

To visit every T in a model in place, use `for T &x = &reflect.each<T>(&model)[]` or its package traversal. The compiler visits value fields, arrays and tuple positions in order, including private fields allowed to the declaring module. It skips reference fields and standard-library representation. A traversal is only a for-header source; a function with result `reflect.Each<T>` may return one traversal. Unions, maps, recursive structures containing T and const writable visits are `TRAVERSAL`. `reflect.each_paths<T>(model)` gives the writable visits as stable checkpoint keys.

Tuples are unboxed value products: `(int, string) pair = (1, "one")`. Destructure them with `(int n, string text) = pair`, `_` to discard, or `(n, text) = pair` for existing places. Reference patterns use `&` on every bound leaf and the source. The same patterns work in collection loops and by-value union match cases. Tuple text quotes strings; keys may contain recursively hashable tuple elements. Tuples have no `.0`, `[0]`, members, ordering or C ABI form.

A mutable local reference may start unbound: `int &r`. Bind it with
`&r = &value` before reading or writing its target, or using `&r`.
A definitely unbound access is `UNBOUND_REFERENCE`; an access after a
conditional binding checks the address at runtime unless every path binds it.
An unbound declaration resets the reference each time it executes, including
in a loop body. `auto &r` requires an initializer to determine its type.
Reference parameters are lent by the caller and cannot be rebound.


Multiple-array `for` selects matching positions, not all pairs:

```quidra
int[] prices = [10, 20]
int[] quantities = [2, 3]
int total = 0
for int price = prices[], int quantity = quantities[]
    total += price * quantity
print(total) // 80
```

Sources run once from left to right, each captured as a value snapshot. All
lengths must match before the body starts (`FOR_LENGTH` otherwise); empty
matching arrays have no iterations. The initial form supports Array values
only, with no reference, range, traversal, pattern or explicit index mixtures.

## Local declaration scope

`local` precedes `const` or the declared type. It is optional in ordinary function/if/for blocks and ordinary function parameters. Names become visible at their declaration and remain visible only in that block and its inner control blocks. A local does not become a class member or implicitly enter another function/class definition. At class body level and in class headers, use it for initialization-only temporaries.

## Parallel iterations

Use `parallel for x < count` for independent iterations, for example
`a[x] = x` into a prepared array. Each value is a task scheduled on the shared
worker pool; execution order is unspecified and all iterations join before the
next statement. Use integer ranges or scalar Array value/zip headers. Bounds and
sources are evaluated once, left to right; zip lengths match before scheduling.
Do not read an output array in its body, alias its storage, or update it with
`+=`. Only direct `a[loop_variable]` output writes have the initial disjointness
proof. `continue` ends one iteration; group-escaping `break`/`return`, reference
headers, real ranges and unproven effects are `PARALLEL_FOR`. Boxed integers and
pure calls retain the existing owner-thread node execution rule.
