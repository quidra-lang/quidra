Write a program that takes no input and prints exactly four lines:

  SUM <s>
  MAX <m>
  EVENS <e>
  JOINED <j>

where, from the integer sequence produced by the generator below with n = 50 terms:
  <s> is the sum of all terms
  <m> is the largest term
  <e> is how many terms are even
  <j> is the first five terms written in order, separated by single hyphens

The generator is the Park-Miller minimal-standard LCG:
  state starts at 7
  each next term is: state = (state * 48271) mod 2147483647, then the term is (state mod 1000)

So the first term is (7 * 48271 mod 2147483647) mod 1000, and so on for 50 terms.
All four values are computed from those same 50 terms.
Exit with status 0.
