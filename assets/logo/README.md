# Official Quidra logo assets

This directory contains the official Quidra visual identity.

Upload the approved PNG originals using these exact filenames:

- `quidra-logo.png` — symbol + wordmark
- `quidra-symbol.png` — symbol only
- `quidra-wordmark.png` — wordmark only

The PNG files should be committed from the approved originals without redesigning or rasterizing them again.
