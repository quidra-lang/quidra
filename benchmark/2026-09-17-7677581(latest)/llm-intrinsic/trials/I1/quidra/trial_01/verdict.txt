NOTE on a harness quirk observed, not a program defect:
  `python3 inverse.py gen_00.txt > candidate.qui` (the single-argument form given
  in the task text) does NOT read gen_00.txt. inverse.py's main() only treats
  argv[0] as an input path when len(argv) >= 2; with one argument it falls through
  to reading stdin, which is empty under that redirect. The result is a 0-byte
  solution.qui that the compiler accepts (build exit 0) and that runs to exit 0
  printing nothing -- a silent false negative. Use the stdin form (`< gen_00.txt`)
  or the two-argument form (`inverse.py gen_00.txt solution.qui`).
