F20.P2 / TypeScript -- NONE evidence, captured on the frozen toolchain

The frozen semantic_compression recipe for TypeScript is
   build: tsc --strict --target es2022 --module nodenext FILE.ts
   run:   node FILE.js
tsc emits a JavaScript source file. There is no object file, no shared library and no
executable, so there is no symbol table for the platform symbol lister to inspect and no
unit in which a symbol named `add2` could be defined.

$ tsc --strict --target es2022 --module nodenext F18.P1.ts && file F18.P1.js
F18.P1.js: ASCII text
$ nm F18.P1.js
/Applications/Xcode.app/Contents/Developer/Toolchains/XcodeDefault.xctoolchain/usr/bin/nm: error: F18.P1.js: The file was not recognized as a valid object file

TypeScript has no extern "C" form, no #[no_mangle]/#[unsafe(no_mangle)] analogue and no
calling-convention attribute: the language emits JavaScript and the ECMAScript reference
defines no external linkage of any kind.

nm field of the evidence record: "no compiled artifact under the frozen recipe".
N-reason: N-1 (per doc 01 support_rubric NONE final paragraph, which assigns N-1 to
exactly this case and directs that it be recorded as a NONE with justification, not N/A).
