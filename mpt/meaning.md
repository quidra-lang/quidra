# Meaning-counting checklist

Count distinct facts guaranteed by the visible code and the applicable language or library specification, assuming a complete, error-free program. Give 1 point per guaranteed fact at the stated observation point; unknown or inapplicable facts get 0. Assess each parameter, element, axis or other target separately, and never count the same fact twice. Examples are independent minimal excerpts in valid enclosing contexts; omitted declarations and bodies cannot supply evidence. A different known value, passing model or permission still qualifies.
